☁️ Cloud Monitor Dashboard

A real-time Cloud Resource Monitoring Dashboard designed to track, analyze, and visualize cloud infrastructure performance efficiently. This system helps organizations monitor CPU usage, memory consumption, storage utilization, and network activity through an interactive and user-friendly interface.

🚀 Project Overview

Cloud environments generate large volumes of performance data. Managing these resources manually often leads to inefficiencies, delayed issue detection, and poor optimization.

The Cloud Monitor Dashboard provides:

📊 Real-time resource monitoring

📈 Visual performance analytics

🖥️ Centralized cloud infrastructure view

⚡ Quick detection of performance bottlenecks

🗄️ Structured database for resource tracking

This project is ideal for academic purposes, mini-projects, or as a foundation for enterprise cloud monitoring solutions.

🔧 Setup Instructions

Clone the repository

git clone https://github.com/your-username/cloud-monitor-dashboard.git

Import the database:

mysql -u root -p < schema.sql
mysql -u root -p < seed.sql

Install dependencies (if backend exists):

pip install -r requirements.txt

Run the application and open dashboard.html.
